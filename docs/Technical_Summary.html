BetterPresser — Technical Summary & DSP Specification

Plugin: BetterPresser (VST3 & Standalone)
Developer: Archie DSP
Framework: JUCE 8 (C++17)
Validation Standard: Tracktion PluginVal (Strictness Level 10)

1. Executive Summary

BetterPresser is a high-performance digital dynamic range compressor developed in C++ using the JUCE framework. The system is engineered to provide transparent, low-distortion feed-forward compression with continuous second-order polynomial soft-knee transitions, switchable Peak/RMS sidechain detection, dynamic auto-makeup compensation, and zero-allocation real-time audio thread execution. The plugin includes a resolution-independent procedural vector user interface featuring an illuminated analog VU meter with second-order physics-based needle ballistics and a live scrolling compression graph.

2. DSP Mathematics & Signal Processing Architecture

2.1. Continuous Polynomial Soft-Knee Gain Computer

To eliminate discontinuous first derivatives in the static compression curve (which creates audible harmonic distortion and clicks), BetterPresser implements a quadratic polynomial transition across knee width W:

Static Transfer Characteristic yG(xG) [in dB]
• For   xG ≤ T − W⁄2   (Linear uncompressed region):
    yG(xG) = xG

• For   T − W⁄2 < xG ≤ T + W⁄2   (Polynomial transition region):
    yG(xG) = xG +
(1⁄R − 1) · (xG − T + W⁄2)22W


• For   xG > T + W⁄2   (Linear compressed region):
    yG(xG) = T +
xG − TR
Target Gain Reduction:   GRtarget(xG) = yG(xG) − xG ≤ 0 dB

2.2. Dual Detection Path (Peak & RMS)

Sidechain Envelope Detectors
1. Peak Mode:   xlin[n] = max(|sL[n]|, |sR[n]|)

2. True RMS Mode: Running leaky integrator with τrms = 30 ms (αrms = exp(−1 / (τrms · fs))):
    MS[n] = αrms · MS[n−1] + (1 − αrms) · ½ (sL2[n] + sR2[n])
    xlin[n] = √max(10−10, MS[n])

2.3. Decibel-Domain Envelope Ballistics

Attack & Release Discrete Difference Equations
• Attack Phase (when GRtarget[n] < EnvdB[n−1]):
    EnvdB[n] = αatt · EnvdB[n−1] + (1 − αatt) · GRtarget[n]

• Release Phase (when GRtarget[n] ≥ EnvdB[n−1]):
    EnvdB[n] = αrel · EnvdB[n−1] + (1 − αrel) · GRtarget[n]
Time constants:   αatt = exp(−1 / (τatt · fs)),   αrel = exp(−1 / (τrel · fs))

2.4. Automatic Makeup Gain Formula

Dynamic Mathematical Compensation
Gauto(dB) = −0.55 · T · (1 − 1⁄R)    (for T ≤ 0 dB)

3. Real-Time Thread Safety & Memory Architecture

  • Zero Heap Allocation on Audio Thread: All audio buffers, filters, and ring buffers are statically allocated in prepareToPlay(). processBlock() performs zero new/delete operations.
  • Lock-Free Atomic Metering: Gain reduction, input peak, and output peak meters communicate with the 60 Hz GUI thread via relaxed memory order atomics (std::atomic<float>).
  • APVTS State Serialization: Full parameter layout managed through AudioProcessorValueTreeState with XML binary stream persistence in getStateInformation() / setStateInformation().

4. Physics-Based VU Meter & Visualizer Engine

2nd-Order Mass-Spring-Damper Needle Model
d2θ/dt2 + 2ζωn dθ/dt + ωn2 (θ − θtarget) = 0
ANSI C16.5 VU parameters: Damping ratio ζ = 0.68, Natural frequency ωn = 22.0 rad/s (300 ms rise time, 1.2% overshoot).
Gaussian-Smoothed Waveform Visualizer
ysmooth[p] = 0.25 · yraw[p−1] + 0.50 · yraw[p] + 0.25 · yraw[p+1]
Subsampled at ~6.0 ms intervals (264 samples/point @ 44.1 kHz) providing a smooth, fatigue-free ~3.3s display window.
